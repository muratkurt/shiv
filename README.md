# shiv

An AI assistant that runs in your terminal, on a jailbroken iPhone.

> **shiv is no longer updated.** Its tools continue in **[shivtools](https://github.com/muratkurt/shivtools)**, same repo. If you keep shiv, install shivtools after it.

## Install

Add `https://muratkurt.github.io/` in Sileo and install **shiv**. Node.js is bundled. Packages are also on each [release](../../releases).

## Requirements

- iOS 15 or newer, rootless (`iphoneos-arm64`) or RootHide (`iphoneos-arm64e`)
- Your own API key, or an OpenRouter account for browser sign-in

## What it does

Chat with a model, let it read and edit files and run commands (it asks first), and keep sessions. Works with OpenRouter, OpenAI, DeepSeek, Moonshot, xAI, Qwen, Z.ai, Groq, Mistral, Together AI, a local Ollama / llama.cpp, or any OpenAI-compatible endpoint. `/help` lists the commands.

## Bugs

Open an [issue](../../issues/new) with your device, iOS version, jailbreak and shiv version.
